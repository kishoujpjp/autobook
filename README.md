# 自動繪本 Autobook

給 5 歲小朋友的中文認字繪本 PWA。輸入認字表，AI（Gemini）幾乎只用表內的字生成約 200 字的小故事（每篇最多 2 個新字），配上 AI 插圖。插圖一開始被迷霧罩住，孩子點讀文字（點按高亮）就按比例吹散迷霧。另有聽音認字遊戲。

## 功能

- **故事**：生成前可點選必用字（最近新加的優先顯示）、輸入或語音輸入追加條件；每個字都是大按鈕，點按有回饋音效並切換高亮；插圖固定不隨文字捲動，迷霧隨已讀比例散開，全部讀完有彩帶慶祝；文字區用上下翻頁按鈕整行翻頁；故事書架保存歷史（含插圖，離線可重讀）；「準備發音」可預先快取整篇字音，之後點字即唸。故事顯示字形跟隨語系設定即時繁簡轉換（內建 OpenCC 單字對照表），字表字卡維持輸入時的原字形。
- **遊戲**：自動出 10 題（答錯多、練習少的字加權優先），開始前把題目語音快取到 IndexedDB（之後重複利用）；點喇叭唸字、二選一字卡，答對 +1 星、答錯 -1，音效與彩帶回饋，結算給星星。
- **字表**：批次貼上加字（自動去重）、統計（總數／已點讀／還沒用過／常答錯）、排序（最新／最少用／最常用）、整理模式刪字；每個字記錄被納入故事的次數，生成時優先挑次數少的字。
- **設定**：繁／簡切換（介面＋故事）、Gemini API Key、點字發音開關、模型與語音角色（進階）、清快取、版本號。
- **教具卡**（遊戲頁）：認字卡／認詞彙兩種親子面對面大字卡，詞彙由內建 8000 常用詞離線詞庫拼出（jieba 詞頻 × CC-CEDICT，不用 AI）；上一張/下一張換題無上限；優先出現次數少的字；點字循環標記 綠（學會，3 天冷卻不出題）→ 紅（還不會，1~2 張後重出）。
- **本地帳號**：設定頁可新增帳號（名字＋身分），家長不受限、小孩看不到「字表」「設定」；右上角頭像可切換帳號，小孩切回家長要過算術家長確認；頭像可從 10 個內建向量小動物選擇或上傳照片（存本機）。
- **跟讀**：英語單字/短句跟讀練習。題庫手動輸入或 AI 出題；每題 AI 配圖（懶生成快取）＋TTS 示範發音（快取）；小孩按麥克風跟讀，發音判定走**裝置內建語音辨識**（Web Speech API，零雲端延遲），逐詞紅黃綠上色＋0-100 分（寬鬆鼓勵導向），結束給平均分。若在 iOS PWA 內辨識不可用，app 會提示改用 Safari 開啟。
- 全介面自繪、禁用 iOS 長按選字與雙擊縮放；音效全部 WebAudio 合成，無需素材。
- 沒填 API Key 時為示範模式（示範字表＋示範故事），可先體驗操作。

## 本地預覽

```bash
python3 -m http.server 8123
```

開 `http://localhost:8123`。

## 部署到 iPad

PWA 安裝（加入主畫面）需要 **HTTPS**。把整個資料夾放上任一靜態空間即可，例如：

- GitHub Pages / Cloudflare Pages / Netlify（拖上去就行，無 build step）

之後在 iPad Safari 開網址 → 分享 → 加入主畫面。首次載入後 App 外殼可離線使用（生成故事仍需網路）。

## 設定 Gemini

到 [Google AI Studio](https://aistudio.google.com/apikey) 取得 API Key，貼進設定頁。Key 只存在裝置 localStorage，直接從瀏覽器呼叫 Google API，不經過任何中介伺服器。

預設模型（設定頁「進階」可改）：

| 用途 | 模型 |
|---|---|
| 故事文字 | `gemini-2.5-flash` |
| 插圖 | `gemini-2.5-flash-image` |
| 語音 | `gemini-2.5-flash-preview-tts`（角色 `Leda`） |

## 技術備註

- 純前端 ES modules，無 build step。資料：localStorage（設定／字表／故事文字）＋ IndexedDB（插圖、語音 blob）。
- 故事生成走 JSON schema 輸出，前端驗證「表外新字 ≤ 2」，超標自動帶回饋重試（最多 3 次），仍失敗則取新字最少的一版。
- 迷霧為 canvas 疊層，以故事 id 做種子決定揭開順序，重新開啟 App 進度一致。
- 繁簡轉換表 `js/zhconv.js` 由 OpenCC 的 TSCharacters/STCharacters 生成（1 對 1 主要對應、僅 BMP）；故事儲存保持生成當下字形，顯示時才轉換，高亮索引不受影響。
- Service worker 為 network-first：線上永遠載最新版，離線時退回快取。版本號在 `js/store.js` 的 `VERSION`；改版時同步改 `sw.js` 的 `CACHE` 名稱以清舊快取。
